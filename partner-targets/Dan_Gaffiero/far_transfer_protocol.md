## Trident G Far Transfer Protocol - General theoretical hypothesis

The central hypothesis is that far transfer is more likely when cognitive training does **not** merely increase fluency on a practised task, but repeatedly trains the learner to recover the same underlying relational structure across changed task surfaces, cognitive layers, interference, delay and applied use.

In Trident-G terms:

```text
→ Gf search
→ relation discovery
→ wrapper validation
→ vertical reconstruction
→ feedback
→ Gc consolidateing
→ later Gf re-entry
```

The practical principle is:

```text
Do not consolidate fluency.
consolidate portable structure.
```

This generalises across attention training, working-memory training, SR-style predictive learning and explicit inference training. The specific trained operation may differ, but the transfer hypothesis is the same: a useful cognitive relation must survive **surface change**, **load**, **lure interference**, **vertical reconstruction** and **delayed re-entry**. The protocol source states this explicitly as a framework for training portable adaptive intelligence rather than narrow task improvement, built around horizontal transfer, vertical transfer, niche deployment and delayed consolidation.

## The core process

### 1. Gf phase: structured search under uncertainty

Training begins by placing the learner in a task environment where the relevant relation is not immediately overlearned. The learner must search for what matters:

```text
surface cue
→ relevant variable
→ candidate relation
→ testable structure
```

This is the **fluid search** phase. The aim is not random novelty or maximal difficulty, but a controlled state in which the learner must identify the relevant variables and relations.

In an attention task, the relation may be “what signal matters under noise”.
In a working-memory task, it may be “which relation must be held across delay”.
In an SR task, it may be “which transition predicts what comes next”.
In explicit inference, it may be “what follows if this relation is true”.

---

### 2. Horizontal transfer: change the wrapper, preserve the invariant

Once performance in one surface format begins to stabilise, the task surface changes while the underlying relation is preserved.

```text
Wrapper A
→ relation X

Wrapper B
→ same relation X

Wrapper C
→ same relation X
```

The behavioural signature should be:

```text
local learning
→ flattening
→ wrapper perturbation
→ temporary dip
→ recovery
→ mixed-wrapper stability
→ delayed survival
```

This is the horizontal transfer test. The learner should not merely improve in Wrapper A. They should recover the same relation when the surface changes.

This applies broadly:

| Training domain    | Horizontal invariant                  | Wrapper examples                               |
| ------------------ | ------------------------------------- | ---------------------------------------------- |
| Attention          | target signal / task-relevant feature | arrows, motion, gratings, symbolic cues        |
| Working memory     | relation held across delay            | clean relation, noisy relation, mixed relation |
| Binding WM         | relation-context conjunction          | colour, location, role, rule context           |
| SR / prediction    | transition or reachability structure  | visual graph, motion stream, symbolic graph    |
| Explicit inference | reasoning form                        | symbolic, nonsense-semantic, domain-semantic   |

The protocol specification treats wrapper swaps, modality changes, near-miss foils, mixed wrappers and delayed re-checks as the core tests of horizontal transfer. 

---

### 3. Vertical transfer: move the relation through the cognitive stack

Horizontal transfer asks:

```text
Can the same relation survive surface change?
```

Vertical transfer asks:

```text
Can the same relation be extracted, held, bound, predicted from, reasoned with and used?
```

The general stack is:

```text
readiness / trainable state
→ attention / evidence extraction
→ variable abstraction
→ relational invariant abstraction
→ relational working memory
→ binding / context maintenance
→ SR-style predictive mapping
→ explicit reasoning
→ policy selection
→ application
→ feedback
→ delayed re-check
```

This is why the model is not “attention training” versus “working-memory training” versus “reasoning training”. Those are different layers of one transfer architecture. The IQ Coach spec expresses this as five core capacities — Attention Control, Relational Memory, Binding Memory, Path Prediction and Reasoning — where the same relational structure is encountered across multiple cognitive operations rather than in unrelated mini-games.

## Hypothesised mechanisms

### Entropy–mutual information regulation

The proposed mechanism is that effective training alternates between:

```text
entropy
= reopening the search space

mutual-information constraint
= selecting what is relevant, predictive and useful
```

Too much repetition may create a narrow surface routine. Too much novelty may create scatter without consolidation. The protocol therefore introduces controlled perturbations near local asymptote: enough stability has formed for a relation to exist, but not so much that the surface routine has hardened.

Wrapper perturbation is useful because it forces the learner to ask:

```text
What changed on the surface?
What stayed the same underneath?
```

### Relational invariant abstraction

The key trained object is the **relational invariant**: the structure that remains stable when the surface changes.

Examples:

```text
same change
valid relation
wrong-lag lure
path still reaches goal
rare but possible
context changes the rule
evidence supports claim
evidence only appears to support claim
```

Far transfer is hypothesised to depend on learning not only the relation, but also its **boundary conditions**: where it holds, where it fails, and what near-miss cases look like.

### SR-style predictive mapping

For SR-based tasks, the relation becomes predictive:

```text
state
→ transition
→ consequence
→ reachable future
```

This is the bridge from pattern learning to inference. The learner is not just detecting what is present now; they are learning what usually follows, what is rare, what is impossible, and whether a path still reaches a target.

### Global-workspace / explicit reasoning bridge

A relation becomes more transferable when it can be made explicit, selected and reused:

```text
visual relation
→ symbolic relation
→ verbal relation
→ applied scenario
```

This is why explicit inference is not just an “extra test”. It is a vertical bridge. It asks whether the structure learned in lower-level training can be recovered as a reasoning operation.

### Reinforcement and Gc consolidateing

The protocol should reinforce the whole route, not just the answer:

```text
state
→ evidence sampling
→ variable abstraction
→ relation recovery
→ working-memory maintenance
→ predictive inference
→ reasoning / policy selection
→ action
→ feedback
→ delayed reuse
```

A correct answer by surface shortcut has low transfer value. A correct answer after wrapper change, lures, prediction and delayed re-check is stronger evidence of portable structure.

---

## General Gf → Gc → Gf spiral

The theory is not a simple practice loop:

```text
practice
→ improvement
→ more practice
```

It is a spiral:

```text
Gf opens the search space.
Training identifies candidate relations.
Wrapper changes test portability.
Vertical tasks test whether the relation can be used.
Feedback selects what worked.
Gc stabilises the bounded structure.
Later Gf re-enters with richer material.
```

So Gc is not just stored knowledge. In this model, good Gc is a **bounded predictive-control module**:

```text
relation
+ variables
+ boundary conditions
+ foils
+ valid wrappers
+ transition structure
+ reasoning handle
+ deployment cues
+ feedback history
+ delayed recovery
```

Later fluid cognition can then search using better building blocks.

## What counts as evidence

The strongest proposal framing is to separate local improvement from transfer evidence.

| Outcome                              | Interpretation                          |
| ------------------------------------ | --------------------------------------- |
| Better performance on trained task   | local learning                          |
| Recovery after wrapper change        | horizontal transfer                     |
| Stable performance in mixed wrappers | flexible invariant recovery             |
| Resistance to near-miss lures        | boundary precision                      |
| Relation survives delay              | consolidation candidate                 |
| Relation supports prediction         | SR-style vertical transfer              |
| Relation supports explicit reasoning | reasoning transfer                      |
| Relation appears in real tasks       | niche/application evidence              |
| External benchmark shift             | external anchoring, not proof by itself |

The app specification makes the same distinction: app-native capacity scores estimate how much structured information the user can handle, whereas Transfer Score tests how well that structure survives transfer tests.

## Evidence base and theoretical motivation

The proposed protocol is motivated by three converging lines of evidence: computational models of learning as information-driven self-organisation, empirical evidence that human learning curves often contain discontinuities or phase-like transitions, and the broader transfer literature showing that local task improvement is not sufficient evidence of far transfer.

### 1. Computational motivation: learning as entropy–mutual information regulation

A central motivation comes from Zhang and Tang’s computational model of nonequilibrium learning. Their account suggests that productive learning reflects a balance between two pressures: entropy, which supports broad exploration of possible update directions, and mutual information, which constrains those updates toward task-relevant structure. In this framework, heavy-tailed update distributions are not treated as random noise. They are a signature of self-organising learning in which small local refinements coexist with occasional larger reorganisations.

<img width="2048" height="1117" alt="image" src="https://github.com/user-attachments/assets/bdcc8e57-3597-4228-8555-7ad5e1a4a0f1" />

This maps naturally onto the proposed far-transfer protocol. In a standard training task, practice may progressively increase mutual-information constraint: the learner becomes better at extracting what matters in the current task surface. However, if training continues only within the same surface, the system may stabilise a narrow, wrapper-specific policy. The protocol therefore introduces controlled perturbations — wrapper swaps, near-miss foils, mixed formats and delayed re-checks — at points where local performance begins to flatten. The aim is to reopen entropy-driven search while preserving the same underlying relational invariant.

The hypothesis is that useful far-transfer training should not maximise repetition or novelty in isolation. It should regulate the alternation between stability and perturbation:

```text
learn a relation
→ approach local asymptote
→ perturb the wrapper
→ recover the invariant
→ mix wrappers
→ re-check after delay
```

In this interpretation, a wrapper swap is not merely variety or engagement design. It is a structured perturbation intended to test whether the learner has formed a deeper relation that can survive the loss of the original surface cue.

### 2. Empirical motivation: piecewise learning curves and transition costs

The second motivation comes from Donner and Hardy’s analysis of individual learning curves. They found that learning often fits better as a sequence of piecewise power-law segments rather than as one smooth curve. Importantly, later learning segments can begin with a brief performance drop at the transition point, followed by performance that eventually surpasses the earlier segment.

<img width="504" height="501" alt="image" src="https://github.com/user-attachments/assets/18f4e0c7-4eeb-4e92-87b9-fb6a8dc47361" />

This is highly relevant to transfer-focused training. A temporary dip after a wrapper shift should not automatically be interpreted as failure. It may be the behavioural signature of a new learning segment: the learner’s previous policy is being disrupted, and the system must reorganise around a deeper or more general structure.

The proposed protocol uses this logic directly. It treats the pattern:

```text
local improvement
→ flattening
→ perturbation
→ temporary dip
→ recovery
→ higher mixed-wrapper stability
```

as a candidate transfer curve rather than a simple performance curve.

The key measurement question is therefore not only whether performance improves within one task, but whether the learner shows faster recovery after successive perturbations. If later wrapper shifts produce smaller dips, faster recovery and stronger delayed retention, this would suggest that training is building a reusable structure rather than only a surface-specific routine.

### 3. Why the protocol is needed: limits of narrow cognitive training

The broader cognitive-training literature motivates a cautious approach. Working-memory training and other brain-training paradigms often produce gains on trained or closely related tasks, but far transfer to broad intelligence measures is much less reliable. This does not imply that cognitive training is impossible. It suggests that task repetition alone is an insufficient design principle.

The proposed protocol responds to this limitation by making transfer the object of training and measurement from the beginning. It separates:

```text
trained-task gain
from
wrapper recovery

near transfer
from
mixed-wrapper stability

same-session performance
from
delayed recovery

implicit graph learning
from
explicit reasoning transfer

self-reported application
from
external benchmark change
```

This makes the programme evidence-generating rather than claim-driven. It does not assume that better game performance equals better cognition. It asks whether a trained relation survives surface change, interference, delay and vertical reconstruction.

### 4. Relation to predictive-map and reasoning evidence

The SR / Path Prediction layer is motivated by successor-representation and predictive-map accounts of cognition, in which current states are represented partly in terms of expected future states. We can envisage these represntations as conditional probability graphs.

<img width="1560" height="1247" alt="image" src="https://github.com/user-attachments/assets/e50fcfc9-1a2d-427e-af2f-29ad2e025190" />


This provides a principled bridge between pattern learning and flexible prediction. In the protocol, users are not only trained to recognise a current state; they are trained to learn transition structure, distinguish likely from rare or impossible transitions, and judge whether a path can still reach a target.

The explicit inference layer then tests whether the same structure can be recovered in symbolic, nonsense-semantic and domain-semantic reasoning. This is important because far transfer should not stop at implicit pattern learning. A relation that becomes explicitly usable can support explanation, strategy selection, rule checking, counterfactual search and applied decision-making.

Inductive reasoning training provides additional motivation for this direction because it targets comparison, relation abstraction and rule recovery rather than isolated task repetition. The present protocol extends this logic by embedding reasoning transfer inside a wider horizontal and vertical training architecture.

### 5. Testable predictions

The protocol makes several falsifiable predictions.

First, wrapper swaps should produce a temporary dip followed by recovery, rather than either no disruption or complete collapse. Second, repeated wrapper swaps should reduce future recovery cost. Third, users should show stronger transfer when wrapper swaps are introduced near local performance flattening rather than too early or after extensive overtraining. Fourth, near-miss foils should improve boundary precision and reduce false transfer. Fifth, gains should be more meaningful when they appear not only in trained-task scores but also in mixed-wrapper performance, delayed re-checks, SR-style prediction probes and explicit reasoning bridges.

A minimal empirical validation pathway would therefore compare:

```text
standard repeated practice
versus
practice + wrapper perturbation
versus
practice + wrapper perturbation + vertical reasoning bridge
versus
full protocol with delayed re-checks
```

The expected result is not merely larger trained-task gain. The predicted advantage of the full protocol is greater portability: reduced wrapper-switch cost, better lure resistance, stronger delayed recovery, improved path-prediction-to-reasoning transfer and stronger performance on independent reasoning benchmarks.

### 6. Summary

The protocol is best understood as a mechanistic hypothesis about how far transfer might be made more likely. Zhang and Tang provide a computational rationale for alternating exploration and task-relevant constraint. Donner and Hardy provide empirical motivation for treating learning as segmented, with transition points and temporary dips. The wider transfer literature motivates caution: local improvement alone is not enough. The proposed contribution is therefore a structured training and measurement protocol that tests whether useful relations become portable across wrappers, cognitive layers, lures, delay and external benchmarks.

## Grant-ready summary paragraph

The proposed training framework is based on the hypothesis that far transfer is more likely when cognitive training targets portable relational structure rather than task-specific fluency. Across attention, working memory, predictive learning and explicit inference, the protocol trains users to identify task-relevant variables, recover relational invariants under changed wrappers, resist near-miss lures, maintain relations under delay, use them for prediction and reasoning, and re-enter them after time or applied use. Mechanistically, the framework treats learning as a regulated alternation between entropy-driven search and mutual-information constraint: task practice stabilises a candidate relation, wrapper perturbation reopens search while preserving the invariant, vertical reconstruction tests whether the relation can be held, bound, predicted from and reasoned with, and delayed re-checks test whether the structure has become reusable Gc. The central claim is not that any single attention, working-memory or reasoning exercise guarantees far transfer, but that a structured programme of invariant recovery, vertical reconstruction, foil sharpening, feedback and delayed consolidation provides a testable route for building and measuring portable cognitive structure.
